# Code Review Workflow

When triggered to review changes, follow these steps:
1. **Lint Configurations**: Verify `plugin.json` and `plugin.yaml` syntax.
2. **Spelling check**: Search changed lines for spelling anomalies against the Australian English register.
3. **Command check**: Ensure all slash commands in `/commands/` have proper descriptions and clean prompt templates.
